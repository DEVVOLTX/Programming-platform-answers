# موقع إجابات المنصة التعليمية

موقع لعرض إجابات جاهزة فقط (بدون نظام أسئلة أو إرسال من المستخدمين)، لقسمي **JavaScript** (المستويات 43–54) و **Python** (الفصول 1–25).

## كيف تشغّل الموقع

- افتح ملف `index.html` مباشرة في المتصفح، أو
- ارفع مجلد الموقع بالكامل على أي استضافة (Netlify، GitHub Pages، استضافة عادية...).
- يحتاج الموقع اتصالًا بالإنترنت مرة واحدة فقط لتحميل الخط ومكتبة تلوين الأكواد (من روابط CDN)، وباقي الموقع يعمل من الملفات المحلية.

## كيف تضيف/تعدّل الإجابات

كل الإجابات موجودة في مجلد `js/data/` فقط، ولا حاجة لتعديل أي ملف آخر (لا HTML ولا CSS ولا app.js) عند إضافة أو تعديل إجابة.

- إجابات JavaScript: `js/data/javascript/levelXX.js`
- إجابات Python: `js/data/python/chapterXX.js`

كل ملف يحتوي على مصفوفة أسئلة بهذا الشكل:

```js
window.DATA.javascript[43] = [
  {
    question: 1,          // رقم السؤال
    text: "",              // نص السؤال (اختياري، يمكن تركه فارغًا)
    answer: `الكود هنا`,   // نص/كود الإجابة (استخدم backtick للأسطر المتعددة)
    copy: true             // true لإظهار زر النسخ، false لإخفائه
  },
  {
    question: 2,
    text: "",
    answer: `...`,
    copy: false
  }
];
```

فقط أضف عناصر جديدة داخل المصفوفة بنفس الشكل، والموقع سيعرضها تلقائيًا بترتيبها.

## كيف تضيف مستوى أو فصلًا جديدًا مستقبلًا

1. أنشئ ملف بيانات جديد بنفس الأسلوب، مثلًا `js/data/javascript/level55.js`.
2. أضف الرقم `55` إلى مصفوفة `ids` الخاصة بـ JavaScript في ملف `js/data-manifest.js`.
3. لا حاجة لأي تعديل آخر — سيظهر المستوى تلقائيًا في الصفحة الرئيسية وفي شبكة المستويات.

نفس الفكرة تنطبق على فصول Python (عدّل مصفوفة `ids` الخاصة بـ Python في `data-manifest.js`).

## بنية الملفات

```
index.html              الصفحة الرئيسية للموقع
css/style.css            التصميم
js/app.js                منطق العرض والتنقل والبحث (لا يحتوي إجابات)
js/data-manifest.js      تعريف الأقسام والمستويات/الفصول المتاحة
js/data/javascript/      ملفات إجابات JavaScript (level43.js ... level54.js)
js/data/python/          ملفات إجابات Python (chapter01.js ... chapter25.js)
```

## البحث

- في الصفحة الرئيسية: اكتب رقم مستوى أو فصل للانتقال إليه مباشرة.
- داخل صفحة أي مستوى/فصل: اكتب رقم السؤال أو جزءًا من نصه (إن توفر) لتصفية الأسئلة المعروضة.
